# Elaine's Devs — Portfolio

Personal portfolio for **Elaine Muhombe**, a MERN Stack Developer. Built with vanilla HTML, CSS, and JavaScript.

## Features

- Hero with typing animation and scroll-reveal effects
- Skills section with icon badges
- Projects gallery with filtering, sorting, and pagination
- Process timeline
- Contact form with Nodemailer backend and mailto fallback
- Responsive design with accessibility and SEO metadata

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | HTML, CSS, JavaScript |
| Backend | Node.js (serverless function) |
| Email | Nodemailer (SMTP) |
| Deployment | Vercel |

## Development

```bash
npm install
npm run dev
```

## Structure

```
├── index.html          # Main entry
├── css/                # Stylesheets (base, components, responsive)
├── js/                 # Client-side scripts
├── api/                # Serverless contact function
├── assets/             # Resume PDF and other assets
├── .plan/              # Design and implementation docs
└── vercel.json         # Deployment config
```
